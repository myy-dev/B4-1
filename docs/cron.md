# cron 실행 주기

cron의 시간 항목은 앞에서부터 분 → 시 → 일 → 월 → 요일 순서입니다.

```text
*  *  *  *  *  실행할 명령어
│  │  │  │  │
│  │  │  │  └─ 요일 (0~7, 0과 7은 일요일)
│  │  │  └──── 월   (1~12)
│  │  └─────── 일   (1~31)
│  └────────── 시   (0~23)
└───────────── 분   (0~59)
```

`*`는 해당 항목의 모든 값을 뜻합니다. 실행 주기 예시는 다음과 같습니다.

```text
*  *  *  *  *   → 매분 실행
0  *  *  *  *   → 매시 정각에 실행
0  9  *  *  *   → 매일 오전 9시에 실행
30 9  *  *  1   → 매주 월요일 오전 9시 30분에 실행
0  9  1  *  *   → 매월 1일 오전 9시에 실행
```
